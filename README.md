## 古桥千秋——中国历代桥梁数据可视化

## 项目简介

本项目以"古桥千秋"为主题，构建了一个多维度的中国古代桥梁数据可视化系统。通过时间、地理、类型、装饰 四大维度，全面展示中国古代桥梁的发展历程与文化内涵。

项目采用纯前端技术实现，结合ECharts数据可视化和Three.js 3D交互，将传统历史文化与现代数字技术深度融 合，为用户提供沉浸式的桥梁文化体验。

## 功能特点

## 1. 时间维度

- 按朝代顺序展示44座中国古代桥梁

- 支持朝代筛选功能

- 点击桥梁卡片查看3D模型和照片

- 数据分析页面独立分离，优化布局

## 2. 地理维度

- 中国地图交互式展示桥梁分布

- 点击地图散点查看桥梁详细信息

- 省份桥梁数量排名和占比统计

- 响应式地图交互体验

## 3. 类型维度

- 6种桥梁类型详细分析（拱桥、梁桥、廊桥、索桥、浮桥、木拱廊桥）

- 桥梁类型网络关系图

- 点击类型卡片展示典型桥梁详情

- 类型时间趋势分析

## 4. 装饰维度

- 拱桥形状词云展示装饰元素

- 点击装饰元素查看相关图片

- 图片放大缩小功能

- 装饰元素分布统计

## 技术栈

- 前端基础：HTML5 + CSS3 + JavaScript

- 数据可视化：ECharts 5.x


3D渲染：Three.js + GLTFLoader

响应式设计：适配PC端和移动端

资源管理：本地glb模型与photos图片资源

## 技术栈详细介绍

## 核心库

ECharts 5.x：百度开源的交互式图表库，用于时间轴、地理分布、类型分析等数据可视化


- Three.js：JavaScript 3D库，用于加载和渲染3D桥梁模型

- GLTFLoader：Three.js的模型加载器，用于加载GLB格式的3D模型

## 可视化工具

- 时间轴图表：展示桥梁按朝代分布

- 地理散点图：展示桥梁在地图上的分布

- 类型关系图：展示不同桥梁类型的关系

- 装饰元素词云：展示桥梁装饰元素的分布

- 趋势分析图：展示桥梁发展的时间趋势

## 技术特色

- 模块化设计：各功能模块独立分离，便于维护

- 响应式布局：适配不同屏幕尺寸

- 性能优化：3D模型加载优化，确保流畅体验

- 用户交互：丰富的交互效果，提升用户体验
